# Experience Summary

For this activity, I built a Personal Note-Taking System using Python and PyQt. The app lets a user create notes with a date, topic, content, and multiple image attachments. It also lets the user view all notes and filter them by date, topic, and keyword search.

Using AI helped me get started faster because it helped turn the assignment requirements into a clear project structure. The AI suggested separating the app into different files, such as the GUI file, the data model, and the storage file. This made the project easier for me to understand because the code was not all placed in one large file.

I also used AI to help debug and improve the program. The first version worked for the basic requirements, but I still had to look at the generated code carefully. Some parts needed improvement, such as handling bad image attachments, preventing crashes from a corrupted notes file, and making the user interface easier to use. After reviewing the output, the app was improved with safer storage, better attachment handling, clearer status messages, and a cleaner design.

One thing I learned is that AI can be very helpful, but it should not be trusted blindly. For example, Vercel first tried to treat the project like a Python web app, but this assignment was actually a desktop PyQt app. The better solution was to publish the source code on GitHub and create a static Vercel page for the professor to access the project easily.

Overall, this activity showed me that AI can help with planning, coding, debugging, testing, and documentation. However, I still needed to understand the code, check the requirements, test the program, and decide whether the AI-generated solution made sense for the assignment.
